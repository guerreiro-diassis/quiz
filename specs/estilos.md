## estilos do quiz

## contexto

quiz no estilo visual de um programa de perguntas e respostas super conhecido no Brasil

### regras

escrever apenas css relacionado aos estilos.
aplicar as classes criadas nos elementos é permitido.

### restrições

não escrever nenhum arquivo .js

### stack e padrões

crie e aplique css utilizando o padrão CSS BEM (block element modifier)

### critérios de aceitação

html devidamente estilizado, com bom espaçamento, levando em conta os elementos que vão aparecer e sumir enaunto a pessoa interage om o quiz

### verificação

todas as classes css seguem o padrão bem.
todos os elementos foram estilizados.

nenhuma classe foge do padrão.

todas as devidas classes CSS foram aplicadas.
